# CareerBoost — Мансапты бастауға арналған мобильді қосымша

CareerBoost студенттер мен жас мамандарға тағылымдама және жұмыс орындарын іздеуге көмектеседі. Пайдаланушы кәсіби профиль толтырады, өз дағдыларына сай бос орындарды іздейді және жіберген өтінімдерінің күйін бір жерден бақылайды.

## Жобаның мақсаты

Алғашқы жұмысын іздеп жүрген пайдаланушыға үш сұраққа бір жерден жауап беру: «Маған қандай бос орындар сәйкес келеді?», «Қайсысына өтінім жібердім?» және «Келесі қадам қандай?».

## Жоспарланған функциялар

- **Кәсіби профиль:** білімін, дағдыларын және қызықтыратын мамандығын көрсету.
- **Бос орындарды іздеу:** ұсыныстарды мамандық, қала және жұмыс форматы бойынша сүзу.
- **Таңдаулылар:** қызықтырған бос орындарды кейін қарау үшін сақтау.
- **Өтінімдер күнделігі:** өтінім жіберілген компанияны, лауазымды және күнді белгілеу.
- **Өтінім күйін бақылау:** пайдаланушы әр өтінімнің күйін өзі жаңартады: «Жіберілді», «Сұхбатқа шақырды», «Ұсыныс түсті» немесе «Жабылды».

## Жүйе архитектурасы

Android қосымшасы іздеу шарттарын Retrofit арқылы Laravel REST API серверіне жібереді. Сервер MySQL дерекқорынан сәйкес бос орындарды алып, нәтижені қосымшаға қайтарады. Кәсіби профиль, таңдаулылар және өтінімдер әр пайдаланушының аккаунтына байланысты сақталады.

## Жобалау үлгілері — Design Patterns

| Топ | Үлгі | Жоспарланған қолданылуы |
|---|---|---|
| Creational | Builder | Пайдаланушы таңдаған сүзгілерден іздеу сұрауын құрастыру. Мысалы, қала мен мамандық көрсетіліп, жұмыс форматы бос қалуы мүмкін. |
| Creational | Abstract Factory | Ұсыныс түріне сай карточка мен сүзгі жұбын жасау: тағылымдама үшін екеуі де мерзімге, ал жұмыс орны үшін тәжірибе талабына негізделеді. |
| Behavioral | Template Method | Өтінімді күнделікке қосудың ортақ ретін бекіту: деректерді тексеру → жазба жасау → сақтау. Тексеру қадамы өтінім түріне қарай өзгереді. |
| Behavioral | Strategy | Іздеу нәтижесін сұрыптау тәсілін пайдаланушының таңдауына қарай ауыстыру: жарияланған күні немесе дағдыларға сәйкестігі бойынша. |
| Structural | Adapter | `VacancyAdapter` арқылы бос орын деректерін Android-тағы `RecyclerView` карточкаларына байланыстырып, лауазымды, компанияны және қаланы көрсету. |
| Behavioral | Visitor | Өтінім кластарына есептеу кодын қоспай, жұмыс пен тағылымдама бойынша сұхбат кезеңіне жеткен өтінімдер санын бөлек шығару. |

## Құжаттама және командалық жұмыс

Жоба талаптары (`SRS`), архитектура сипаттамасы (`ARCHITECTURE`), жобалау үлгілері (`PATTERNS`), API құжаттамасы және пайдаланушы нұсқаулығы `docs/` бумасында сақталады.

Тапсырмалар GitHub Issues арқылы бөлінеді. Әр өзгеріс жеке тармақта әзірленіп, Pull Request арқылы тексерілгеннен кейін `main` тармағына біріктіріледі.
